# STG Overview

STG is a web application focused on sharing institutional information in a structured, clear, and accessible way. The project is designed as a modern presentation site with multiple sections, including institutional information, relevant updates, action lines, and contact information.

## Purpose

The platform aims to provide a simple and professional experience for users who need to access public-facing information quickly and clearly. It is especially suitable for organizations, institutions, or initiatives that need a clean digital presence.

## Main sections

- Quiénes Somos
- Acciones
- Información Relevante
- Contacto

## Frontend stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router

## Project characteristics

- Responsive layout
- Route-based navigation
- Modular page structure
- Lightweight frontend architecture
- Easy deployment through Vercel

## Intended use

This project can be used as a base for:

- institutional web pages
- project landing pages
- organizational information portals
- public information sites

## Related files

- `src/App.tsx` — route definitions
- `src/pages/` — page-level content
- `tailwind.config.js` — styling configuration
- `vercel.json` — deployment settings

## Maintenance notes

Keep the content and structure aligned with the actual institutional messaging. If new sections are added, update the routes and documentation consistently.
